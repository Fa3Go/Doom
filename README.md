# 毀滅戰士 JS

仿《毀滅戰士》(DOOM)的第一人稱射擊遊戲，有兩個版本：

| 檔案 | 版本 | 技術 |
| --- | --- | --- |
| `index.html` | **重製版**(現代 3D) | Three.js / WebGL：即時光影、法線貼圖、光暈後製、粒子特效 |
| `classic.html` | 經典像素版 | 純 Canvas 光線投射，320×200 復古畫面 |

兩個版本都不需要安裝，用瀏覽器直接打開即可。重製版使用的 three.js 已經放在 `lib/` 裡，可以離線遊玩。

## 重製版操作

| 操作 | 鍵盤 / 滑鼠 | 手機 |
| --- | --- | --- |
| 移動 | W A S D | 左半邊螢幕拖曳(推到底就是奔跑) |
| 瞄準 | 滑鼠(上下左右自由瞄準) | 右半邊螢幕拖曳 |
| 開火 | 左鍵 / Ctrl | 「開火」 |
| 奔跑 / 跳躍 | Shift / 空白鍵 | 「跳」 |
| 近戰 / 處決 | F / V / 右鍵 | 「近戰」 |
| 換武器 | 1–4、Q、滾輪 | 「換槍」 |
| 開門 / 出口 | E(或直接走過去) | 直接走過去 |
| 小地圖 | M / Tab | — |
| 暫停 | Esc | — |

## 重製版內容

- **處決系統**：敵人血量低時會搖晃並發出橘光，靠近按 F 處決，會噴出自動吸向你的補血球
- **爆頭**：打中頭部傷害加倍，準星會顯示不同顏色的命中標記
- **4 種武器**：手槍(無限子彈)、霰彈槍、機槍、電漿步槍
- **4 種敵人**：殭屍士兵、會側移閃避的小惡魔、衝鋒的粉紅惡魔、魔王地獄男爵(有血條)
- 動態光源(槍口火光、爆炸、燈管閃爍)、彈孔與血跡貼花、連鎖爆炸油桶、受傷方向指示
- 合成的金屬風格背景音樂與帶殘響的音效
- 設定選單：滑鼠靈敏度、FOV、音效/音樂音量、畫質(手機預設低畫質)

武器、彈藥、生命值會帶到下一關；陣亡時會從該關開始時的狀態重來。
