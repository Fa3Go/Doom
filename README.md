# 毀滅戰士 JS

一個仿《毀滅戰士》(DOOM)的第一人稱射擊遊戲,全部寫在單一 `index.html` 裡,不需要任何外部素材或安裝。

## 怎麼玩

直接用瀏覽器打開 `index.html` 即可。

| 操作 | 鍵盤 / 滑鼠 | 手機 |
| --- | --- | --- |
| 移動 | W A S D / 方向鍵 | 左半邊螢幕拖曳 |
| 轉向 | 滑鼠(點擊畫面鎖定游標)/ ← → | 右半邊螢幕拖曳 |
| 開火 | 左鍵 / 空白鍵 / Ctrl | 「開火」按鈕 |
| 換武器 | 1 2 3 / Q | 「換槍」按鈕 |
| 開門 / 使用 | E(或直接走過去) | 直接走過去 |
| 奔跑 | Shift | — |
| 地圖 | M / Tab | — |
| 暫停 | Esc | — |

## 內容

- 光線投射 (raycasting) 3D 引擎:有材質的牆面、地板、天花板,距離霧化效果
- 3 個關卡:機庫、地獄入口、魔王巢穴(最終頭目:地獄男爵)
- 4 種敵人:殭屍士兵(射擊)、小惡魔(火球)、粉紅惡魔(近戰衝鋒)、地獄男爵(三連發綠色火球)
- 3 種武器:手槍、霰彈槍、機槍
- 道具:醫療包、彈匣、霰彈、防彈衣、會爆炸的油桶
- 會滑開的門、經典的狀態列與會流血的主角臉
- 所有音效都是用 WebAudio 即時合成的

武器、彈藥、生命值會帶到下一關;陣亡時會從該關開始時的狀態重來。
